# Nivalora artwork

Pale white/blue butterfly dragon, golden Wurmple eyes, cream split muzzle,
head horn, four wings and a curled tail. The approved front and revised rear
sources are `assets/FrostcoonEvolution/approved_front.png` and `rear_source.png`.

`uv run rebuild --all` runs `art/nivalora.py`: transparent crop, fixed 16-colour
palette, nearest-neighbour sampling and positioning. It writes 160×160 battle
frames and a 128×64 bobbing icon; NIVALORA and FROSTCOON_EVOLUTION share this art.
Preview PNG/GIF files are review snapshots. The Articuno cry and normal-equivalent
shiny remain provisional. [Asset workflow](../../assets/AGENTS.md).
