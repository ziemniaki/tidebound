Tidebound 0.8.5 - Windows x64

This release adds a dedicated Windows player package. Gameplay and save
compatibility are unchanged from 0.8.4.

Extract the entire ZIP, then open Game.exe inside the extracted folder.
Keep Game.exe, both DLLs, Game.ini, mkxp.json, soundfont.sf2 and the game
directories together. Do not launch directly from the ZIP preview.
No Python, Node, RPG Maker editor or development tools are needed to play.

Arrow keys move; Enter interacts; Esc opens the menu or goes back.
F1 displays the key bindings. Save from the in-game menu.
Existing saves remain in %APPDATA%\Tidebound_Opening_0_2.
Extract updates to a new folder; do not delete your save directory.

The executable and DLLs are the unchanged Windows runtime supplied with
the project. This package does not add publisher signing or an installer.
Read CREDITS.md and RUNTIME_SOURCE.md for credits and runtime provenance.
The automated smoke check covers startup, compiled data, a save roundtrip
and graphics. It is not a complete playthrough or audio/controller test.
