# Tidebound 0.8.6

- **Mac launches from Downloads:** fixed the misleading “Unable to load scripts” error in macOS’s temporary launch location. Moving the app to Applications is now optional.
- **Move the game freely:** packages work from folders with spaces and non-ASCII names; Linux shortcuts can point to the launcher from another folder.
- **Saves stay in place:** game files can live in a read-only folder while progress stays in your existing save location.

The Mac app is not notarized, so macOS may still require first-launch approval.
Linux targets Ubuntu 22.04/24.04; additional system libraries may be required.
