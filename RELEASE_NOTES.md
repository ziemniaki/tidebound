# Tidebound 0.8.5

More ways to play, plus a fix for the Mac “damaged app” error after unzipping.

## New

- **Apple Silicon support:** the Mac download runs natively on both Apple Silicon and Intel Macs.
- **Windows and Linux downloads:** dedicated packages for Windows x64 and Linux x86_64.

## Fixed

- **Mac unzip error:** fixed a filename issue that invalidated the app's signature when extracted with Archive Utility. If you downloaded 0.8.5 earlier, replace it with this refreshed download.

## Before you play

- **Your saves still work.** This update changes packaging, not gameplay or progress.
- **Mac:** the app is not notarized. Follow the included launch instructions if macOS blocks it.
- **Linux:** tested on Ubuntu 22.04 and 24.04. Install the libraries listed in the included README.

Choose the Mac, Windows, or Linux ZIP below, unzip it, and follow `READ_ME_FIRST.txt`.
