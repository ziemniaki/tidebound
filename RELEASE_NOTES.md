# Tidebound 0.8.5

More ways to play, plus a fix for the Mac “damaged app” error after unzipping.

- **Apple Silicon support:** the Mac download runs natively on both Apple Silicon and Intel Macs.
- **Windows and Linux downloads:** dedicated packages for Windows x64 and Linux x86_64.
- **Mac unzip fix:** corrected a filename issue that invalidated the app's signature after Archive Utility extraction. If you downloaded 0.8.5 earlier, replace it with this refreshed download.
- **Your saves still work.** This update changes packaging, not gameplay or progress.

On Mac, move Tidebound.app to Applications before launching. The app is not notarized, so macOS may block its first launch.
Linux targets Ubuntu 22.04/24.04; additional system libraries may be required.
