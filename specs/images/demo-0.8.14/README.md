# Demo 0.8.14 screenshot provenance

These 24 PNGs are the selected illustrations referenced by `specs/game-design.md`.
They are byte-for-byte copies from the 42-view aesthetic review captured in the
published Linux native player. All 18 authored overworld maps are represented.
The view numbers retain the numbering of the complete review set.

- Release: https://github.com/ziemniaki/tidebound/releases/tag/v0.8.14
- Release source: `335e525922539a63636d9b5dc5dc72d6edc49098`
- Player ZIP: `Tidebound_Linux_0.8.14_x86_64.zip`
- Player SHA-256: `8d336bd48881c3f206ef5f6fca8007f4503f88a36f97f3459ff623e049189f9e`
- Logical image size: 512 by 384 pixels.
- Capture dates: 14–15 October 2026.

The disposable capture fixture stages the player, pauses dialogue/event
progression and random encounters, and renders ordinary sprites, lighting and
real-time fog. It isolates saves and does not change the release archive or user
saves. The lighthouse pair uses actual lamp states; view 38 waits for a natural
fog-density peak. View 42 uses the existing astral state.

No colour, brightness, contrast or crop edits were applied. The PDF renderer
places the source images at their original aspect ratio. Screenshot attribution
inherits the game and asset credits in `docs/credits.md`.
